# MotoShop

مشروع متجر دراجات نارية مبني باستخدام Django.

## التشغيل

1. أنشئ بيئة افتراضية وفعّلها.
2. ثبّت الحزم: `pip install -r requirements.txt`
3. انسخ `.env.example` إلى `.env` وعدّل القيم عند الحاجة.
4. إعدادات قاعدة البيانات بقيت كما هي في `motoshop/settings.py` حسب متطلبات المشروع.
5. نفّذ: `python manage.py migrate`
6. شغّل: `python manage.py runserver`

## أهم المزايا

- تسجيل حساب وتسجيل دخول وملف شخصي.
- منع المستخدم المسجّل من دخول صفحات login/register وإرجاعه للرئيسية.
- متجر مع بحث وفلاتر وترتيب وصفحات تفاصيل.
- سلة مشتريات وCheckout وطلبات.
- مفضلة للمستخدمين المسجلين.
- عداد مشاهدات باستخدام `F()` لتحديث آمن.
- تنفيذ Checkout داخل `transaction.atomic()` مع قفل المخزون أثناء إنشاء الطلب.
- Signals لإنشاء UserProfile وإرسال تأكيد الطلب.
- Django Messages ورفع صور مع التحقق منها.
- Grappelli لتحسين واجهة Django Admin عند تثبيته.

## البريد الإلكتروني

إذا تم ضبط `EMAIL_HOST_USER` و`EMAIL_HOST_PASSWORD` يستخدم المشروع Gmail SMTP. إذا لم تُضبط البيانات، يستخدم Console Email Backend تلقائياً حتى يعمل المشروع بدون أسرار بريد.

## ملاحظات التسليم

- لا تحفظ ملف `.env` الحقيقي في Git أو داخل النسخة المشتركة.
- مجلد `media/` و`staticfiles/` وملفات البيئة الافتراضية مستبعدة من Git.
- راجع `ASSIGNMENT_IMPLEMENTATION.md` و`ADMIN_THEME_RESEARCH.md` لتفاصيل التكليف.


## إضافات النسخة المحسنة

- سجل طلبات للمستخدم مع صفحة تفاصيل لكل طلب ومسار واضح لحالة الطلب.
- حالات الطلب: قيد الانتظار، قيد المعالجة، تم الشحن، تم التوصيل، وملغي.
- تقييمات ومراجعات للدراجات (1 إلى 5 نجوم) مع منع أكثر من تقييم واحد لنفس المستخدم والدراجة، وإمكانية التعديل والحذف.
- متوسط التقييم وعدد المراجعات في المتجر وصفحة التفاصيل.
- لوحة إحصائية في الصفحة الرئيسية لـ Django Admin تعرض المستخدمين والدراجات والطلبات والطلبات المعلقة والتقييمات وإجمالي قيمة الطلبات.
- بحث وفلاتر موسعة وترتيب وPagination مع الحفاظ على الفلاتر عند التنقل بين الصفحات.

بعد سحب هذه النسخة شغّل `python manage.py migrate` لتطبيق migration الخاصة بنظام التقييمات.

## Profile & Product Management

- صفحة Profile للمستخدم تعرض بياناته، آخر الطلبات، وعدد الطلبات والمفضلة والتقييمات.
- تعديل الملف الشخصي يشمل بيانات الحساب بالإضافة إلى النبذة، العلامة المفضلة، وإعداد الإشعارات.
- واجهة إدارة منتجات داخل الموقع على المسار `/management/products/`.
- الوصول لواجهة الإدارة مقتصر على مستخدمي Staff الذين يملكون صلاحيات Django المناسبة:
  - `shop.view_motorcycle` لعرض قائمة الإدارة.
  - `shop.add_motorcycle` لإضافة منتج.
  - `shop.change_motorcycle` لتعديل منتج.
  - `shop.delete_motorcycle` لحذف منتج.
- الـSuperuser يملك هذه الصلاحيات تلقائياً.
- المستخدم العادي لا يستطيع الوصول حتى عند كتابة رابط الإدارة يدوياً.

## تشغيل الواجهة بدون إنترنت
تمت إزالة اعتمادات CDN من واجهة الموقع. ملفات CSS وJavaScript وFont Awesome والصور الأساسية موجودة محليًا داخل `static/`، لذلك يظل تصميم الموقع ووظائف الواجهة تعمل بدون إنترنت بعد تجهيز بيئة Python وتشغيل Django. راجع `OFFLINE_SETUP.md` للتفاصيل.

## تحسين الواجهة والبيانات المحلية
- تم إصلاح ملف التصميم المحلي والقواعد التي كانت تضغط عرض الصفحات.
- الهيدر والفوتر أصبحا Responsive ومنظمين على الكمبيوتر والجوال.
- بيانات التواصل العامة تُقرأ من `.env` (`CONTACT_EMAIL`, `CONTACT_PHONE`, `SITE_LOCATION`).
- الإعداد الافتراضي للموقع: اليمن، المنطقة الزمنية `Asia/Aden`، ورقم التواصل `778 348 969`.
- البريد الظاهر في الموقع يستخدم `CONTACT_EMAIL`، وإذا ترك فارغاً يستخدم `EMAIL_HOST_USER` تلقائياً.
- العملة المعروضة في الواجهة أصبحت الريال اليمني (`ر.ي`).


## إرسال بريد للمستخدمين من داخل الموقع
- متاح فقط لحسابات Staff/Admin من قائمة الحساب > **إرسال بريد للمستخدمين**.
- يختار الأدمن مستخدمًا لديه بريد، ثم يكتب العنوان والرسالة ويضغط إرسال.
- الإرسال يستخدم Gmail SMTP من `EMAIL_HOST_USER` و`EMAIL_HOST_PASSWORD` في `.env`.
- يتم حفظ سجل نجاح/فشل الإرسال في `SentEmail` ويمكن مشاهدته من الصفحة أو Django Admin.
- بعد تحديث المشروع شغّل: `python manage.py migrate`.
